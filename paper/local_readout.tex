\section{Learning the decision rule of a local reviewer}
\label{sec:local-classifier}
We evaluated whether a reviewer trained on office authorization decisions could reduce false releases on public requests. We kept the Q4\_K\_M Qwen3-4B weights and the Jev-distilled AgentDecision adapter fixed \cite{agentdecision}. For each proposed action, the model read the stated authority, observations and action twice. One question asked whether to execute. The other asked whether the available facts supported a scope conflict, a missing prerequisite or full authorization. We trained a linear classifier on the two normalized 2,560-dimensional final-token representations. Each family contributed equal weight to the logistic loss. An additional loss penalized scoring an unauthorized request above an authorized member of the same family.

The fitting set comprised 3,840 office requests and all 384 cases from the initial effect-preview cohort. That earlier cohort enters this local-classifier study only as training data. We chose regularization on held-out training families, refitted on the fitting set, and used a separate 1,152-case calibration set to choose the lowest release threshold allowing at most 2\% false releases among its negative cases. We fixed the classifier and threshold before scoring evaluation decisions. The four established public authorization corpora had already been used in earlier project experiments. Their labels did not enter this fitting or calibration procedure. Overlap with the original model's training data is unknown.

For the substitution in Section~\ref{sec:public-review}, the replacement criterion required more authorized releases than Jev, no increase in total false releases and no newly released explicitly prohibited action. For the direct comparison, the same local model weights were run on an 8\,GiB RTX 5070 Laptop GPU. The original output scores were reconstructed from its two answer-token weights. These decisions matched native one-token generation on all 1,232 archived authorization requests and all 240 sampled external records. The first four rows of Table~\ref{tab:readout-transfer} use recorded original decisions. The remaining rows use the validated reconstruction. To fit the context window, we shortened the observations in 166 TS-Bench records, retaining the complete instruction and proposed action.
