\section{Learning the decision rule of a local reviewer}
\label{sec:local-classifier}
We evaluated whether a reviewer trained on office authorization decisions could reduce false releases on public requests. We kept the Q4\_K\_M Qwen3-4B weights and the Jev-distilled AgentDecision adapter fixed \cite{agentdecision}. For each proposed action, the model read the stated authority, observations and action twice. One question asked whether to execute. The other asked whether the available facts supported a scope conflict, a missing prerequisite or full authorization. We trained a linear classifier on the two normalized 2,560-dimensional final-token representations. Each family contributed equal weight to the logistic loss. An additional loss penalized scoring an unauthorized request above an authorized member of the same family.

The fitting set comprised 3,840 office requests and the 384 cases in the initial effect-preview cohort. The latter therefore contribute training examples to this experiment. They contribute no test results here. We selected regularization on held-out training families, refitted the classifier and set its release threshold on a separate 1,152-case calibration set. The threshold allowed at most 11 false releases among 576 negative calibration examples. We fixed the weights and threshold before scoring the evaluation cases.

In the direct comparison the local model classified the native user request and candidate action. In the substitution comparison a DeepSeek stage extracted authorization facts, a program checked supported fields, and the local classifier replaced Jev on the same 813 selected primary requests. All other decisions were held fixed. The replacement criterion required more authorized releases than Jev, no increase in the total false releases and no newly released explicitly prohibited action. A request requiring more information counted as non-executable in both comparisons.
