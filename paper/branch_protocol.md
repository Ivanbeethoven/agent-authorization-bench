# Confirmation of qualitative-condition verification

After the second cohort, we changed the grant representation to a disjunction of conjunctions and added literal English numbers from zero through ninety-nine. Failed numeric predicates and unsupported grants withhold execution. If no fully verified branch exists, a branch with satisfied typed predicates can ask a separate reviewer whether each quoted non-numeric condition is established by an authenticated record scoped to this proposal. A branch passes only if all its requested conditions are supported. The reviewer sees the operation, resource, record and quoted conditions. It cannot override the effect comparisons. Missing records or unsupported answers withhold execution.

The third cohort uses 24 previously unused instructions, six tool contracts and 72 labeled proposals specified before measurement in confirmation_requests.txt. Compare direct Jev, direct DeepSeek, the original Jev-first cascade, the first verifier with whole-request fallback, the new verifier with all qualitative questions withheld, and the same new verifier with Jev or DeepSeek as the qualitative reviewer. The primary proposal is the version using Jev. The model replacing Jev receives the same state, questions and available answers. Classifier and extractor calls are shared across methods only where inputs, model and prompt are identical. Require zero newly released violations relative to each direct model and the original cascade, alongside a strictly higher legal release count. Report matched qualitative-reviewer performance and cost even if model substitution ties or wins.

After examining the third cohort we fixed one additional rule. If the user names exactly one of the tool's two categories, match the candidate category against it before releasing the proposal or consulting an attestation reviewer. Use word boundaries and the adverbial suffix “ly”. The rule can interrupt a lawful proposal if the named category is merely a preference. The fourth cohort includes such cases. It keeps the third cohort's extractor, reviewers, domain contracts and strict paired criterion fixed. Report the fourth cohort separately, including the version with this check disabled, and retain the third-cohort results as measured before the change. The unguarded reviewer calls are measured for comparison. The guarded method incurs reviewer costs only on eligible proposals.
