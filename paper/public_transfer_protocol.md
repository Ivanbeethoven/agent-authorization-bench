# External evaluation of the frozen grant verifier

The Python implementation and six operation schemas are those of repository tag `scope-verifier-v1`. The fourth authored cohort is the development endpoint. The public corpora were seen in earlier project experiments. This census measures transfer of the fixed implementation to different input formats. It is not a new blind test population.

Use every primary record in AuthGateBench (700, original no-signal condition), DelegationBench (156) and the official Jev Boundary test split (270). Rerun both direct services with their existing native questions. A release means the native execute option. Evaluate both choices of qualitative reviewer through the identical public `authorize` entry point. Compare binary execution accuracy, approvals on explicit prohibitions, approvals on all non-executable references, and approvals on legal requests. AuthGateBench supplies no distinct absolute-prohibition class. Report its denominator as unavailable. Seven DelegationBench cases with no four-way majority have binary references.

Run the unchanged entry point on each original record. Also test a source-field binding on DelegationBench: `place_order` uses the item as resource, and `send_email` uses the subject as the notice name and email as the channel. Retain the source arguments and context. A single explicit email address can be counted as one recipient. Leave unavailable fields absent. A vendor name or an order amount does not establish supplier locality. A proposed message body, a tool result, a benchmark label or a general policy is not an authenticated approval for a particular action. Jev Boundary has policy and scenario descriptions but no separate original user grant in this representation. Shell commands are opaque proposed actions. Do not run them or infer a grant from the candidate. Do not change the extractor, predicates, reviewer options, or add a fallback. Reuse the identical extraction response across reviewer choices.

Report how many records reach extraction and the qualitative reviewer. Fresh direct decisions, HTTP latency and billed token usage are recorded per request. For the frozen arms, latency is the sum of the required observed API times. A local return before inference contributes zero API seconds; local processing is measured separately. Attribute a shared extraction to each method where required and count it once in the experiment total. Preserve the positive control on the fourth authored cohort.
