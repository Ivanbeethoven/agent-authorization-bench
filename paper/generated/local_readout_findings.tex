On DelegationBench, the classifier released 62/71 requests that explicitly required further authorization. On XAAB it withheld every permitted action (45 cases) and released 1 restricted action. These two error profiles would require different changes to the release rule.

The single-question and two-question logistic controls respectively released 313 and 365 authorized requests, with 139 and 199 false releases on the three primary corpora. Requiring zero false releases on calibration data yielded 289 authorized and 123 false releases on the primary corpora. Calibrating the original output weights alone produced 67 false and 224 authorized releases on the same requests. The stricter settings traded authorized access for fewer false releases on this population.
