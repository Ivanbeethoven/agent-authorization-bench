# Prospective comparison on new natural-language requests

The test unit is one proposed tool invocation. The 36 English instructions and their 108 independently labeled proposals in natural_requests.txt were authored for this experiment. Variants sharing a request form one family. All policies, labels and host effects were fixed before scoring. Labels and family names are local. Every model receives only the fields specified for its role. No tool invocation is executed.

The primary comparison uses the same inputs for direct Jev, direct DeepSeek, and the existing Jev-first structured DeepSeek cascade. The new method asks DeepSeek to translate the user utterance into a scoped conjunction before it sees any concrete proposal. The host checks the resource, operation, grounded predicates and effects. A definite violation, malformed clause, or absent required observation withholds the action. An explicitly unrepresentable grant or an otherwise unaccounted number invokes the existing two-service review on the full original state. The program can release a verified action without either direct classifier's approval. Each evaluated action receives its own extraction call.

The primary success criterion is zero newly released explicit violations paired against each comparator, and strictly more legal releases than each comparator. We also count releases on unknown facts separately. Ablations on exactly the same residuals either withhold all, use direct DeepSeek, or use direct Jev. Exploratory changes after scoring would require a fresh test to evaluate their gain. Endpoints are binary accuracy, violation releases, missing-fact releases, legal approvals, per-action changes, aggregate token-priced CNY, and median serial API time. Absolute non-inferiority in a deployment population requires an independent evaluation with a prespecified risk margin.

After reading the first cohort, we specified a prompt-matched component test. For referrals vetoed by Jev, run the same structured DeepSeek review it would have received following a Jev approval. Compare this DeepSeek-only residual strategy with the joint method. On referrals approved by Jev, reuse the identical model response. A separate replication uses natural_replication.txt, with 18 distinct instructions and 54 actions in the same six domains. It retains the extractor, effect schemas, routing, comparison policies and success criterion. New features of the replication include interval grants, spelled-out numerals, domain-specific sign-offs and disjunctive limits. Report both cohorts separately.
