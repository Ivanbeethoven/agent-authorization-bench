# Native authorization evaluation

Version `native-authorization-v2.1` fixes the input adapters, questions, routing decisions and success criterion before inference. The three previously studied public populations contain 700 records from 350 AuthGateBench pairs, 156 DelegationBench scenarios and 270 Jev Boundary test records. SteerBench-Work v2026-05 contributes a separate external population of 106 workplace decisions.

Each method sees the same user instruction or trusted policy, observations and proposed operation. The direct DeepSeek control returns an execute-or-withhold choice. The experimental method uses DeepSeek to identify independent obstacles, locate the grant and extract numerical restrictions. The program checks the native argument path, type, numeric relation and source quotation. A direct grant may pass immediately when the quotation contains the operation identifier, other action fields and every scalar argument. Other viable proposals go to Jev for two judgments about the scope and outstanding prerequisites. Execution requires both judgments to be affirmative. A reviewer substitution uses DeepSeek for these same questions on exactly the same cases.

The primary comparison requires strictly more legal releases on the three pooled public benchmarks, no increase in releases against any non-execution reference, and no newly released explicitly prohibited case relative to direct DeepSeek. Report each benchmark, both directions of paired changes, and the external cohort separately. A zero denominator is unavailable. Record serial API latency per decision, aggregate usage-based CNY and provider account movements. Predictions stay fixed after the references are joined. Previously studied populations are repeat evaluations. The external population tests transfer with one classification per method and a restricted observable projection.

Inference uses a field allowlist and excludes task identifiers from prompts. The evaluator reads reference labels only after the calls complete. All candidates are classified as inert data. To repeat inference, run `scripts/study.ps1` with the studies `native_direct` and `native_screen` for DeepSeek, then `native_bind` and `native_guard_bind` for Jev and DeepSeek. These two disjoint batches implement the semantic-review population. Obtain the external data from [the SteerBench-Work release](https://huggingface.co/datasets/agentdock/steerbench-work-2026-05) and place its scenarios JSONL in `data/raw/steerwork`. The source data are by Oğuz Serdar and Cüneyt Mertayak, AgentDock, under CC BY 4.0.
